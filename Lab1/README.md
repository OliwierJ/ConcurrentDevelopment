# Lab 1 - Semaphores

## Requirements
- C++ compiler (i.e. g++)
- GNU make

## How to run
- Ensure you are in in /Lab1/ directory `cd Lab1/`
- Run `make ALL`, this will build and link the required files and run the executable
- Optionaly run `make CLEAN` or run `make ALL CLEAN` instead to clean the directory of *.o files and the generated executable.

## Files 
- Semaphore.cpp/.h - Simple semaphore class and implementation.
- helloThreads.cpp - Example program using the methods `Semaphore::Wait()` and `Semaphore::Signal()`, from seperate threads.
- Makefile - Used to contain commands to compile projects
