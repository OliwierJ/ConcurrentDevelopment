# Lab 1 - Barrier and Rendezvous

## Requirements
- Go 1.27+

## How to run
- Ensure you are in Lab1/ directory `cd Lab1/`
- Run the command `go run rendezvous.go` to run the rendezvous program
- Run the command `go run barrier.go` to run the barrier program

## Files 
- `barrier.go` - Example program of a barrier using mutex and channels
- `rendezvous.go` - Example program of two threads at a rendezvous using two channels
- `go.mod` - Go module file
